# 캐시노트 쿠폰 추출기 (Cashnote Coupon Extractor) 🚀

캐시노트 마켓플레이스에서 구매한 다양한 전자 쿠폰(신세계/이마트, 문화상품권, 현대백화점, 롯데백화점 등)을 자동으로 스캔하고 관리할 수 있도록 돕는 브라우저 북마클릿 도구입니다.

[English Version](./README.md)

---

## 주요 기능

- **이미지 분석 AI (Canvas API)**: 쿠폰 이미지의 '사용 완료' 도장을 픽셀 단위로 정밀 분석하여 사용 여부를 실시간으로 판별합니다.
- **주문 일자별 신뢰도 판별**: 브랜드별 분석 시스템 도입 시점 이전의 주문은 `⚠️ 확인 필요` 상태로 분류하여 분석 오류를 최소화합니다.
- **바코드 뷰어**: 미사용 신세계/이마트 상품권을 좌우 슬라이드 형태의 바코드로 즉시 확인하여 오프라인 매장에서 바로 사용할 수 있습니다.
- **구입 내역 대시보드**: 날짜별로 구매한 품목과 현재 상태를 한눈에 파악할 수 있는 히스토리 기능을 제공합니다.
- **스마트 로그 분리**: 분석 과정의 긴 상세 로그는 숨기고 최종 결과만 깔끔하게 보여주며, 필요 시 [LOGS] 버튼으로 상세 내용을 확인할 수 있습니다.
- **모바일 최적화**: 더블 탭 확대 방지 및 터치 친화적 인터페이스를 적용하여 스마트폰 브라우저에서도 쾌적하게 작동합니다.

## 사용 방법 (원격 로더 방식 추천) 🌟

이 방식을 사용하면 코드를 매번 업데이트할 필요 없이, GitHub에 올라온 최신 기능을 즉시 사용할 수 있습니다.

1. 브라우저의 즐겨찾기(북마크)를 새로 하나 생성합니다.
2. 주소(URL) 칸에 아래 코드를 복사해서 붙여넣습니다.

```javascript
javascript:(function(){
  var script = document.createElement('script');
  script.src = 'https://cdn.jsdelivr.net/gh/krazyeom/cashnote/cashnote_remote.js?t=' + Date.now();
  document.body.appendChild(script);
})();
```

등록이 완료되면, [캐시노트 구매 목록 페이지](https://market.cashnote.kr/orders)에서 해당 북마크를 클릭하면 실행됩니다.

## 보안 및 주의사항

- **개인정보 보호**: 본 도구는 사용자의 브라우저 내에서만 동작하며, 어떠한 개인정보나 인증 토큰도 외부 서버로 전송하지 않습니다.
- **분석 정확도**: 이미지 분석 방식의 특성상 100%의 정확도를 보장하지 않을 수 있습니다. 중요한 쿠폰은 반드시 실제 사용 여부를 다시 한번 확인하시기 바랍니다.
- **책임 제한**: 본 도구의 사용으로 인해 발생하는 모든 문제에 대한 책임은 사용자 본인에게 있습니다.
